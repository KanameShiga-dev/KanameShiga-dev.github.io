# 情報漏洩ビンゴ 2026夏〜秋

2026年6月1日〜10月16日に国内で公表された主な情報漏洩・漏洩のおそれの事案から、毎回24件を引いて作るビンゴカードです。収録48件のうち、続報で漏洩が確認されなかった3件と別種の事案1件は抽選対象外です。網羅的な一覧ではありません。

- マスをタップすると「漏」の判が押され、公表日・件数・状況・公表元リンクが表示されます
- 中央は FREE（お詫びとお知らせ）
- 「新しいカード」で引き直し、「印を消す」でリセット
- 印の状態はブラウザの localStorage に保存されます

## 公開方法（GitHub Pages）

このフォルダを既存の `KanameShiga-dev.github.io` リポジトリの `leak-bingo/` に配置します。既存サイトの Pages 設定を使い、公開先は `https://kanameshiga-dev.github.io/leak-bingo/` です。

依存ファイルなし。フォントのみ Google Fonts から読み込みます。

## データについて

- 規模には人数、レコード数、上限値が混在します。「漏えい確認」と「漏えいのおそれ」を区別して表示し、全件流出と解釈しません
- 各項目のリンク先に公表資料や解説を記載しています。夏から追加した事案は各社の一次発表で確認しました。既存の9〜10月分は[セキュリティ対策Labの集計](https://rocket-boys.co.jp/security-measures-lab/2026-sep-oct-japan-data-breach-exposure-scale/)も参照しています
- データ更新は `index.html` 内の `POOL` 配列を編集してください（`ok:1` = 漏えい確認、`ok:0` = おそれ・可能性、`cleared:1` = 続報で漏えいなし、`exclude:1` = 別種の事案。後二者は新しいカードから除外）
- 既存のカードと印は localStorage で維持されます。更新前に作ったカードには、その後の調査で漏えいが否定された項目が残る場合があります。その場合は項目の続報を確認し、「新しいカード」で引き直してください
